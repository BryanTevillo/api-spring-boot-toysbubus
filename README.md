# API Spring Boot - ToysBubus

## Descripción
Una API para gestionar los productos y usuarios de ToysBubus, una tienda en línea de juguetes.

## Tecnologías
- Spring Boot
- PostgreSQL
- JWT para autenticación
- JPA/Hibernate para manejo de base de datos
